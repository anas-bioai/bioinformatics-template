# 🧬 DNA Sequence Analysis Project

This project performs bioinformatics analysis on DNA sequences using Python and Jupyter Notebook.

It demonstrates fundamental concepts in computational biology such as sequence analysis, gene prediction, and protein translation.

---

## 🔬 Features

- 📊 GC Content Analysis
- 📊 AT Content Analysis 
- 🔍 Motif Detection (ATG start codon)
- 🧬 ORF (Open Reading Frame) Prediction
- 🔄 DNA → mRNA Transcription
- 🧪 RNA → Protein Translation
- 🎨 Data Visualization (plots & heatmap)
